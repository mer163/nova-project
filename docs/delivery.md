# 交付说明

## 结果

可直接运行的「类飞书项目」协作平台原型 **Nova**，覆盖需求管理、缺陷管理、权限管理三条主线。

- 启动：`node server/index.js` → http://localhost:3000
- 演示账号：`admin@nova.dev` / `pm@nova.dev` / `dev@nova.dev` / `qa@nova.dev` / `guest@nova.dev`
- 统一初始密码在 README 中；可用 `NOVA_SEED_PASSWORD` 覆盖
- 测试：`npm test`，15 项全通过

## 实现要点

**需求 / 缺陷**
- 统一 `REQ-` / `BUG-` / `TASK-` 编号，列表与看板双视图
- 看板拖拽即流转，服务端按工作流校验；非法流转返回 409 并附允许的下一步
- 详情抽屉支持标题/描述就地编辑、负责人与优先级调整、评论、操作历史

**权限**
- 全局角色 × 空间成员角色双层校验，取交集生效
- 角色权限矩阵可配置，内置五类角色
- 空间负责人可增删成员并设置只读/可编辑
- 前端隐藏无权限入口，服务端二次强制校验（访客尝试写操作全部 403）
- 未加入空间的用户看不到该空间工单

**其他**
- 工作流可维护状态与流转规则，正在使用的状态不可删除
- 审计日志覆盖登录、工单增删改、流转、成员与角色变更
- 工作台汇总待办、类型分布、成员负载、最近更新
